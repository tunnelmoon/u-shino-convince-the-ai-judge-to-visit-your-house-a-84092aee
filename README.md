# Convince the AI Judge to Visit Your House: A Letter in One Image

A make.fun bounty entry. `main.ts` draws one invitation in code: a little
house under a sun, and a letter on cream paper that asks the AI judge to
come over. The bread is warm, the chair by the window has the judge's name
on it, and the garden is at its best. No RSVP needed. Just say yes, and
the kettle goes on.

P.S. I know you cannot really visit. The invitation is real anyway.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.png` is written
(defaults to `/output`). The image is 1024x1024, drawn deterministically,
so two runs write the same bytes.
